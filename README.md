# 📚 Bookstore

A dynamic kids' bookstore web application built using **HTML, CSS, and JavaScript**.

Bookstore is a frontend practice project where most of the UI is generated dynamically using JavaScript. The HTML structure is kept minimal, while books, categories, and interactive elements are rendered from JavaScript data.

## 🌸 About The Project

Bookstore is designed as a kids' book browsing application where users can explore books, view details, interact with books, and save preferences.

The main goal of this project was to practice building a data-driven frontend application where JavaScript controls the rendering logic instead of manually creating HTML content.

The project focuses on:

- Dynamic UI rendering using JavaScript
- Managing book data separately from HTML
- Creating reusable template functions
- Handling user interactions
- Working with browser local storage
- Building responsive layouts

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

## ✨ Highlights

- Dynamic book rendering from JavaScript data
- Browse different books and categories
- View book information and story summaries in popup dialogs
- Like and dislike books
- Add and read comments
- Store user interactions using LocalStorage
- Responsive design for different screen sizes
- Minimal HTML with JavaScript-driven content generation
